# 截图目录

README 引用的图片放这里：

| 文件名 | 内容 | 建议尺寸 |
| :--- | :--- | :--- |
| `widget.png` | 主挂件界面 | 380×560（已提供） |
| `pill.png` | 折叠后的胶囊 | 52×52 |
| `settings.png` | 设置页 | 540×660 |

已有 `widget.png` 由 `tools/capture-screenshots.ps1` 自动生成。
其余两张可以用系统截图工具补：

- **胶囊**：启动挂件 → 点 ✕ → 用 `Win+Shift+S` 框选蓝色小方块 → 保存为 `pill.png`
- **设置页**：点挂件右上角 ⚙ → `Win+Shift+S` 框选整个设置窗口 → 保存为 `settings.png`
